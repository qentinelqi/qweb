File input discovery test

Test multiple input[type=file] elements in light DOM, nested open shadow DOM and same-origin iframes. All inputs have volatile IDs, no labels, and no stable CSS class. Most file inputs are hidden, but three are visible: top-level light DOM #1, top-level shadow DOM #2, and iframe A light DOM #1.

Expected order (document order, recursively descending into open shadow roots): top-level light #1, top-level shadow #2, nested shadow #3, top-level light #4. Each iframe is a separate document: frame A has #1 light and #2 shadow; frame B has #1 nested shadow and #2 light.
